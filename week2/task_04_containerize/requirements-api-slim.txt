# The slim API image (`--build-arg API_VARIANT=slim`, or `API_VARIANT=slim make up`;
# stretch goal: under 1 GB).
# Same service, but the local embedding model (all-MiniLM-L6-v2) runs on ONNX Runtime
# via fastembed instead of PyTorch, so torch (~750 MB), sentence-transformers,
# transformers, scipy and scikit-learn are dropped. LOCAL_EMBEDDINGS_BACKEND=fastembed
# is set in the image. Versions come from constraints.txt, plus a pin for fastembed, the one
# package the local venv does not have (resolved for Python 3.14 on 2026-11-16).
